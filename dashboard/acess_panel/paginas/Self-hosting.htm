FASE 01

O Alicerce: Hypervisor Proxmox

O Proxmox será instalado diretamente no hardware (Bare Metal), eliminando dependências de sistemas operacionais domésticos. Nele, a VM da Brotherhood terá controle total.

Configuração VM Alpha (Ubuntu 24.04):
• CPU: 2 Cores | RAM: 3GB | Disco: 25GB
• Rede: Modo Bridge (Conexão direta com roteador).
FASE 02

O Desafio do ASN e IP Próprio

Transformar a Brotherhood em um Sistema Autônomo (ASN) significa deixar de ser cliente para se tornar parte do esqueleto da rede mundial.

  • Registro: Registro no NIC.br para obter bloco /24.
  • Protocolo BGP: Necessário roteador com suporte a Border Gateway Protocol.
  • Alternativa: Uso de IP Fixo empresarial apontado para o Proxmox (Efeito visual de soberania mantido).
FASE 03

Implementação FRPS (Soberania de Software)

Dentro da VM Ubuntu, o servidor de tunelamento centraliza as conexões vindas do ASN/IP Fixo.

# Comando de persistência Korvado
sudo ./frps -c frps.toml
