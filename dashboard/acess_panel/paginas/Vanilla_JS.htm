Sistema de Injeção Modular

Seu projeto funciona como um "LEGO" digital em Vanilla JS, injetando componentes via JavaScript puro:

01 header.js (Injeta o Topo)
02 Conteúdo HTML (O corpo da página)
03 pagination.js (Injeta o Navegador)
04 footer.js (Injeta o Rodapé)

Vantagens do Vanilla JS

Frameworks como React ou Angular trazem "canhões para matar formigas". Sua abordagem oferece:

  • Zero Configuração: Salve e funcione.
  • Performance Real: Carregamento instantâneo.
  • Controle Total: Você domina cada ponto e vírgula.
O navegador não precisa baixar uma biblioteca de 500kb para renderizar um menu de 1kb.

Dica de Ouro: O Loader Central

Para manter o seu index.html limpo, você pode centralizar as chamadas em um único arquivo:

// loader.js - Centralizador de Peças
import './header.js';
import './pagination.js';
import './footer.js';
