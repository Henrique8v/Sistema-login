Sinergia de Motores: Python & C++

PROTOCOLO DE INTEGRAÇÃO DO SISTEMA-LOGIN

1. Diferença Fundamental de Execução

No ecossistema Brotherhood, o C++ e o Python desempenham papéis distintos com base em como o Windows processa suas instruções.

Python: O Motor Interpretado

Precisa de um "motor" instalado para ler o código toda vez que ele roda. Para o XAMPP, usamos o Python instalado diretamente no sistema, permitindo que o PHP dispare scripts .py sem depender de IDEs abertas.

C++: O Binário Compilado

Diferente do Python, o C++ gera um arquivo .exe independente. Uma vez compilado (via Code::Blocks ou o script executar_cpp.py), ele roda nativamente no Windows sem necessidade de compiladores no servidor de destino. O custo é um binário ligeiramente maior devido à importação de bibliotecas para dentro do executável.

2. Gestão de Ambiente e IDEs

Regra de Ouro: Não desinstale o PyCharm ou o Code::Blocks. As IDEs são seus painéis de controle para debug e escrita em "bolhas" controladas (ambientes virtuais). O Python Raiz no sistema é o motor que serve ao XAMPP.
  • Python Raiz: Motor global acessível pelo PHP.
  • PyCharm: Ferramenta de edição e processamento pesado (GPU/IA).

3. Tutorial: Configurando o Path no Windows

Para que o comando python funcione em qualquer terminal ou via PHP, o executável deve estar nas Variáveis de Ambiente.

  1. Pressione Win + R, digite sysdm.cpl e dê Enter.
  2. Vá na aba Avançado e clique em Variáveis de Ambiente.
  3. Em "Variáveis do Sistema", localize Path e clique em Editar.
  4. Clique em Novo e adicione o caminho da sua instalação: C:\Users\lorde\AppData\Local\Programs\Python\Python314\
  5. Adicione outro para os scripts: C:\Users\lorde\AppData\Local\Programs\Python\Python314\Scripts\
  6. Mova esses dois caminhos para o topo da lista para evitar conflitos com a Microsoft Store.

Resolvendo o Conflito Microsoft Store (Aliases)

Se o comando abrir a loja, vá em: Configurações > Aplicativos > Aliases de execução do aplicativo e desative o Instalador do Aplicativo para python.exe e python3.exe.

4. Implementação no PHP (Maestro)

Para garantir que o PHP não se perca na hierarquia de permissões ou diretórios, use a sintaxe absoluta do Windows para o executável.

// No seu PHP (Sistema-login/my_dashboard.php)
$python = "C:\Users\lorde\AppData\Local\Programs\Python\Python314\python.exe";
$script = "C:/xampp/htdocs/Sistema-login/scripts/python/limpeza_arquivos.py";

// O shell_exec envia para o CMD com tratamento de erros (2>&1)
$resultado = shell_exec("$python \"$script\" 2>&1");

Dica de Barra:

Use DIRECTORY_SEPARATOR para compatibilidade total, embora o CMD moderno aceite / para scripts, o executável do Windows exige \.

5. Tratamento de Saída UTF-8

Para que o PHP receba corretamente caracteres especiais (acentos) dos seus scripts Python, force o wrapper de saída:

import sys
import io

# Força a saída do console a usar UTF-8
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')
