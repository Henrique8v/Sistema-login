CSS SIZING LAB & DOCUMENTATION

01. Width e Height

A forma mais direta de controle físico. Afeta o fluxo do layout.

.caixa {
    width: 300px; /* Largura */
    height: 150px; /* Altura */
}
300px x 150px

02. Transform: Scale()

Aumenta/diminui sem alterar o layout ao redor. Ideal para animações.

.botao:hover {
    transform: scale(1.1); /* +10% no hover */
}
SCALE(2.2)

03. Property: Zoom

Ampliação total incluindo textos. Recalcula o layout da página.

.item-grande {
    zoom: 2; /* Dobra o tamanho total */
}
ZOOM 2.2

04. User Resize

Torna o item redimensionável pelo mouse. Exige overflow definido.

.caixa {
    resize: both; /* Horizontal e Vertical */
    overflow: auto;
}
