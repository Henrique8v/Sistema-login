01. TableWidth Adaptation

O seletor .tableWidth garante que, em telas menores que 800px, a tabela utilize 95% do espaço disponível, evitando que o conteúdo fique "espremido" ou transborde. 
@media (max-width: 800px) {
    .tableWidth {
        width: 95% !important;
    }
}

02. PageContent Optimization

O ajuste no #pageContent reduz o recuo interno para 10px. Isso maximiza a área útil de leitura em smartphones, onde cada pixel horizontal é crítico. 
@media (max-width: 800px) {
    #pageContent {
        padding: 10px !important;
    }
}

Por que usar !important neste contexto?

Em sistemas como o my_dashboard.php, muitos estilos podem vir herdados de bibliotecas externas ou do núcleo do Sistema-login. O uso do !important dentro da sua Media Query no principio.css garante que a sua regra de soberania digital prevaleça sobre qualquer estilo padrão quando o dispositivo for detectado como mobile.
