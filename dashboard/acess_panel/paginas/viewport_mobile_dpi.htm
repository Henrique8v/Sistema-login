Manual de Otimização DPI

1. Meta Viewport "Blindado"

Para evitar que o navegador mobile force escalas incorretas em telas de alta densidade:

<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, shrink-to-fit=no">
  • shrink-to-fit=no: Essencial para iOS/Safari.
  • width=device-width: Trabalha com pixels lógicos.

2. O Segredo do Box-Sizing

Evita que padding e bordas empurrem elementos para fora da tela (flutuação lateral).

* { 
    box-sizing: border-box; 
    -webkit-tap-highlight-color: transparent; 
}

3. Unidades Relativas (vw / dvh)

Em DPI alto, prefira vw para containers globais em vez de larguras fixas em px.

Use width: 100vw; max-width: 100%; para garantir o encaixe perfeito.

4. Media Queries de Densidade

Ajuste fino para telas 1080p+ (DPR 3x ou superior):

@media (-webkit-min-device-pixel-ratio: 3), (min-resolution: 288dpi) {
    body { font-size: 95%; }
}

5. Simulação de Teste

No Chrome/Opera GX: F12 > Device Mode > ⋮ > Add device pixel ratio > Escolha 3.

No Firefox: Ctrl + Shift + M > Selecione DPR 3.0.

Dica de Ouro: Use max-width: 100% em todas as imagens e inputs.
