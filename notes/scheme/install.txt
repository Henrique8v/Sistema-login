│   └── FRPC (Fast Reverse Proxy Client) 
│       ├── 1. Token de Autenticação (Mais Comum) 
│       │   ├── frpc.toml:
│       │   ├── auth.method = "token"
│       │   ├── auth.token = "sua_chave_secreta"
│       │   └── Onde fica: Geralmente no bloco [common] ou sob a seção auth (versões 0.52+)
│       ├── 2. OIDC (Open ID Connect)
│       │   ├── O que é: Um método mais avançado usado para autenticação baseada em provedores de identidade.
│       │   └── Como usar: Requer configurar auth.method = "oidc" e preencher os detalhes do provedor no frpc.toml
│       └── Para que o frpc conecte, você precisa, no mínimo:
│           ├── 1. serverAddr: IP do servidor frps.
│           ├── 3. serverPort: Porta de bind do servidor frps.
│           ├── 4. auth.token: A senha compartilhada.
│           ├── 5. Definição de pelo menos um proxy (ex: [[proxies]])
│           └── nota: use token para evitar que terceiros utilizem seu servidor frp
